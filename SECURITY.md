# Security Policy

## Maintainer

This repository is maintained by [@tst609370-create](https://github.com/tst609370-create).

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please report it privately:

1. Visit the repository's [Security Advisories page](https://github.com/tst609370-create/ESIM/security/advisories).
2. If **Report a vulnerability** is available, use it to submit a private report.
3. If private reporting is unavailable, open a [new issue](https://github.com/tst609370-create/ESIM/issues/new) titled **Request for private security contact** without including sensitive details. The maintainer can then establish an appropriate private channel.

Please **do not** disclose exploit details, personal information, credentials, or unpatched vulnerabilities in public issues or pull requests.

A helpful report includes the affected component, potential impact, reproducible steps, and a suggested mitigation where possible. Remove any secrets or personal data from proof-of-concept material.

## Scope

Reports related to the code in this repository, including authentication, session handling, data exposure, input validation, and dependency vulnerabilities, are welcome. Third-party systems and services outside this project's control are out of scope.

## Handling and Disclosure

Reports will be assessed based on their impact and reproducibility. The maintainer may request additional information and, where applicable, coordinate a fix and disclosure. No guaranteed response or remediation timeframe is offered.

This policy documents a reporting channel and does not imply that this project has passed an external security audit or certification.
